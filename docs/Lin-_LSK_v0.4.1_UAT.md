# Lin− / LSK 项目验收指南（v0.4.1）

本轮重点是新建项目目录与 UMAP 的 MS760 时间查询布局。现有项目已经重命名为 `Lin-_LSK`；验收仍必须使用完整副本，不要打开原项目做写入测试，也不要修改 `HSC1_data`。

## 1. 旧项目兼容

1. 先关闭 LMA Studio。
2. 复制整个 `Lin-_LSK` 为一个独立 UAT 副本。
3. 用本候选打开副本，确认既有标注、Track、UMAP 和导出正常。
4. 不应在副本中自动出现新的 `data/annotations/provenance/diagnostics` 布局；旧 v0.4.0 项目保持原目录，由 manifest 原样读取。

项目根目录整体改名不影响打开。不要只移动内部 parquet、SQLite 或事件坐标表。

## 2. 新目录验收

若要验证新目录，必须另选一个不存在或为空的项目目录，从原始输入新建；不要覆盖 `Lin-_LSK` 副本。新项目完成后应只有清晰的顶层职责：

- `data/`
- `annotations/`
- `provenance/`
- `diagnostics/`
- 可选的 `raw_inputs/`
- `lifms_project.json` 与项目自己的 `README.md`

新目录不应出现内部处理版本目录。Green-only 的 Lin− / LSK 输入不应生成空的 red-channel pair 审计；MS 的背景估计文件不是 QC 身份标签。

## 3. UMAP 查询框

1. 打开 UMAP。
2. 将窗口缩窄到普通笔记本或分屏宽度。
3. `MS760 time` 输入框应完整显示 `e.g. 49.001`，控件应自动换行，不能溢出工具栏。
4. 输入 `49.001` 查询；命中的点显示红色轮廓，Clear 后消失。查询不修改标注。

## 4. 分享验证

关闭软件后压缩整个 UAT 项目副本，在另一个位置解压并重命名根目录，再打开。应可继续查看、标注和导出。若项目采用外部原始输入模式，接收方不需要原始 8 GB MS 文件即可浏览和标注，但没有原始文件就不能从头重跑前处理。

## 5. UMAP 坐标切换

1. 只在 UAT 副本中进入“配置 > UMAP coordinates”。
2. 准备另一份包含同一批细胞时间点、但 UMAP1/UMAP2 不同的 CSV（例如批次校正前坐标）。其他列可以保留。
3. 选择 CSV 并点击 `Validate & switch`。切换后既有标注数量、时间模型和峰表应不变，已打开的 UMAP 应刷新，主 CSV 应使用新坐标。
4. 成功后可以移动原 CSV；项目仍应正常显示新坐标，因为软件使用的是项目内副本。
5. 再测试一份故意少一行的 CSV：软件应拒绝，并继续显示刚才有效的坐标。

macOS 候选还要额外验证：首次点击 UMAP 不应无响应；关闭 UMAP 子窗口后再次点击，应恢复同一个窗口，主窗口始终可操作。
