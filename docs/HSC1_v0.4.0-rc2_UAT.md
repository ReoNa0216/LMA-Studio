# HSC1 实际数据验收指南（已被后续候选替代）

当前请使用 `HSC1_v0.4.0_UAT.md`。本文件只保留 rc2 的历史操作记录。

这份指南按界面操作顺序写。目标不是把 HSC1 全部标完，而是确认：项目能正确创建、时间校正可信、候选可以人工审核、UMAP 能同步、导出的 CSV 便于后续按细胞读取。

## 1. 启动与目录

先关闭其他 LMA Studio 窗口，然后直接运行：

```text
lifms_annotation_windows_source\dist\LMAStudio\LMAStudio.exe
```

项目保存路径可以直接填写：

```text
E:\path\to\scMetab\HSC1
```

这个路径必须尚不存在或是空目录。`HSC1_data` 只是原始输入目录，不能把项目保存进去。软件使用“外部引用”时不会复制或改写原始大文件。

## 2. 新建 HSC1 项目

点击“新建项目”，按下表填写：

| 界面项目 | HSC1 设置 |
|---|---|
| 原始文件保存方式 | 外部引用 |
| 项目保存路径 | `scMetab\HSC1` |
| LIF 1 | 通道 G1；绿色；样本标签 `LSK`；勾选“细胞”；选择 `HSC1_data\Lin-_LSK\G1.CSV` |
| LIF 2 | 通道 G2；绿色；样本标签 `Lin−`；勾选“细胞”；选择 `HSC1_data\Lin-_LSK\G2.CSV` |
| MS 文件 | `HSC1_data\Lin-_LSK.txt` |
| 事件坐标 CSV | `HSC1_data\HSC-Lin-LSK-20260809-After-Batch-Correction.csv` |
| 事件标注起点 | `24` min |
| 自动估计时间差的范围 | 先保留 `2.5` min |
| 后段 QC 策略 | 不进行后段巡检 |

不要添加 R1 或 R2。这个实验实际使用的是 G1/LSK 与 G2/Lin−，并且两者属于同一组绿色信号采集时间。软件会自动共享时间基准，不需要用户填写任何内部轴名。

事件坐标 CSV 不要求恰好只有三列。只要能找到 `scan_start_time`、`UMAP1`、`UMAP2` 即可；`CellNumber`、`batch`、`Type` 等其他列可以保留，软件会忽略不用于匹配的列。

## 3. 不知道参考段边界时怎么做

先保留两个参考段：

- 第 1 段：`LSK`，只勾选 G1。
- 第 2 段：`Lin−`，只勾选 G2。

推荐点击“分析已选 LIF 并建议窗口”。建议只根据当前选择的原始 LIF 峰形计算，并不会替你确认实验边界。

如果建议失败，或者你暂时不能确定边界，仍可填写两个合法且不重叠的临时范围，然后不勾选“边界已确认”，点击“生成草稿并进入项目”。点击后按钮应立即显示“正在创建… Ns”，下方会持续显示已等待时间。读取大型 MS 文件可能需要较长时间，请勿重复点击或关闭软件。

草稿进入后只能查看前段“原始”轨迹；其他阶段保持锁定。这是为了防止未确认边界进入时间模型，并不是程序卡住。

## 4. 核对并确认参考段

进入项目后先查看原始轨迹：

1. 用“图窗起点”和“窗口宽度”浏览 G1 的前段峰群及 G2 的后段峰群。
2. 打开“配置”，把每段开始和结束时间调到能够完整覆盖对应参考峰群、又不过多包含相邻区域的位置。
3. 确认 G1/LSK 在前、G2/Lin− 在后；两个范围不能重叠。
4. 分别勾选“边界已确认”，点击“保存项目配置”。

参考边界是这个项目的可编辑参数。不要为了得到某个固定峰数而硬调边界，也不要把本批建议值当成其他数据的全局常量。

## 5. 完成前段时间校正

在“前段参考校准”中逐段检查候选：

1. 自动连线应保持时间先后顺序，不应出现前后交叉。
2. 附近有多个近似匹配峰时应标为需要逐条审核，不能批量自动接受。
3. 接受可信的参考峰关系。
4. 点击“用已接受参考峰预览重算”，检查证据数量、冲突和残差。
5. 点击“应用参考峰时间校正”。

HSC1 的 G1 与 G2 不要求在同一时刻同时出现峰。它们共同估计一个绿色信号相对 MS 的时间平移。

## 6. 理解高置信峰与弱候选峰

软件默认只显示高置信峰；它们是所有自动校准、时间差估计、质控、候选生成和模型拟合的唯一 LIF 证据。

顶部勾选“显示弱候选峰（仅人工细胞配对）”后，会额外显示通过局部噪声和峰形检查的小峰。弱候选峰：

- 不会自动进入前段校准、后段质控或时间模型；
- 不会因为显示出来就自动产生细胞候选；
- 只允许在事件标注阶段，由用户明确选择一个 LIF 峰和一个 MS 事件建立人工细胞关系；
- 人工接受后可以正常进入主 CSV。

MassHunter 显示的许多小峰与 LMA Studio 默认显示的高置信峰数不必相同。核对时请打开弱候选峰显示，并比较相同原始文件、相同时间范围和原始轨迹；不要用事件坐标 CSV 行数反推 LIF 应有多少峰。

## 7. 锁定 MS 后段时间差

进入“后段时间差校正”：

1. 起始位置应为项目设置的 `24 min`。
2. 点击“用无需身份标签的峰估计 MS 时间差”。
3. 查看建议、证据数量、冲突和残差；必要时用滑块微调。
4. 点击“确认并锁定 MS 时间差”。

锁定后才会开放事件标注。若以后修改参考边界、事件起点或相关时间参数，软件必须先提示哪些结果会失效；已有人工标注应保留为历史记录，但时间差和候选必须重算。

## 8. 事件标注与拥挤窗口

进入“事件标注 / QC 巡检”。HSC1 设置为不进行后段巡检，因此这里应只出现细胞候选。

如果 2.5 min 内候选太密，把顶部“窗口宽度 (min)”改为 `0.25`、`0.5` 或 `1.0`，再按 Enter 或点击“显示窗口”。左右箭头会按当前宽度移动。显示窗口宽度只改变浏览范围，不会改变自动估计时间差所用的项目范围。

如果 G1 与 G2 都指向同一个 MS 事件，必须人工选择 LSK 或 Lin− 中唯一可信的关系，不能同时接受。再检查 Track 与 UMAP：点击任一窗口中的事件，应能在另一窗口定位到同一事件；接受或撤销后颜色与状态应同步。

赶时间时不必标完整个 HSC1 才能验收。建议至少完成：

- 前段两段各检查一组参考峰并完成时间校正；
- 24 min 以后分别检查若干个 G1 和 G2 候选；
- 检查至少一个跨通道冲突；
- 显示一个弱候选峰并确认它不会自动配对；
- 人工建立一条弱候选峰细胞关系（若有明确证据）；
- 完成一次 UMAP 双向定位和一次 CSV 导出。

## 9. 导出检查

点击“导出细胞/质控主 CSV”。主表只包含已接受且当前有效的细胞关系和后段质控关系；HSC1 不进行后段巡检，因此通常只有细胞行。

请重点检查：

- 每行都有稳定的 `CellNumber`、LIF 通道、LIF 峰、MS 事件和时间残差；
- `Type` 来自项目中 G1=`LSK`、G2=`Lin−` 的样本标签，不复制坐标源表中的作者标签；
- 前段参考峰、完整模型信息和歧义审计不会混入主 CSV，它们保留在项目审计库中；
- CSV 列数固定且无需解析复杂 JSON，便于后续读取和标注 cell。

## 10. 报错时记录什么

不要删除失败项目。请保留并记录：

- 点击的按钮与完整报错；
- 当时是否仍为边界待确认草稿；
- 图窗起点、窗口宽度、原始/校正后模式；
- 是否显示弱候选峰；
- 项目目录中是否已生成 `annotation_app\annotations\annotation.sqlite`。

截图尽量同时包含顶部控件、通道名、峰点与候选连线。
