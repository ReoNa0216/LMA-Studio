# HSC1 真实数据测试指南

这次直接运行：

```text
lifms_annotation_windows_source\dist\LMAStudio\LMAStudio.exe
```

请先关闭旧版 LMA Studio。这一轮是调试 `dist` 目录，不需要 ZIP 或安装包。

## 1. 项目保存在哪里

新建项目目录可以直接填：

```text
E:\path\to\scMetab\HSC1
```

`HSC1` 是输出项目，`HSC1_data` 是只读原始数据，两者不是同一个目录。不要把项目保存到 `HSC1_data` 里。

第一次测试时 `HSC1` 应不存在或为空目录。以后要重新测试，请换一个新目录，不要覆盖已经做过人工标注的项目。

## 2. 新建项目

1. 点击“新建项目”，保持“外部引用”。
2. 项目目录选择上面的 `scMetab\HSC1`。
3. 添加两个 LIF：

   | 通道 | 检测器 | 科学身份 | 文件 |
   |---|---|---|---|
   | G1 | Green | LSK | `HSC1_data\Lin-_LSK\G1.CSV` |
   | G2 | Green | Lin− | `HSC1_data\Lin-_LSK\G2.CSV` |

   选择 Green 后，软件会自动把 G1/G2 放在同一个 Green 共享时间轴上；不需要自己填“物理时间轴名”。
4. MS 文件选择 `HSC1_data\Lin-_LSK.txt`。
5. 事件坐标 CSV 选择：

   ```text
   HSC1_data\HSC-Lin-LSK-20260809-After-Batch-Correction.csv
   ```

   CSV 只要能找到 `scan_start_time`、`UMAP1`、`UMAP2` 三列即可，不要求整张表只有三列。`CellNumber`、`batch`、`Type` 或其他列都可以保留，软件会忽略非必需列。
6. 事件标注起点保持 `24 min`，后段 QC 保持 `disabled（不巡检）`。

页面中的“可选：实验配置模板”只是快捷填写，不是默认操作；不用它也可以按上表完成配置。

## 3. 不知道参考段边界时怎么做

1. 点击“分析已选 LIF 并建议窗口”。
2. 软件会读取峰形，自动回填 G1/LSK 和 G2/Lin− 的候选开始/结束时间。
3. 此时可以不勾选“边界已确认”，直接点击“生成草稿并进入项目”。
   按钮会改为“正在创建… Ns”并持续显示已等待时间。8 GB MS 文件需要较长时间，请勿重复点击或关闭软件。
4. 草稿项目只显示原始峰形；不会计算校准、不会生成后段 delta，也不会删除任何已有人工标注。高密度窗口默认只标注分区内的代表性显著峰；所有峰圆点仍保留，悬停可查看精确时间，也可用顶部“峰时间标签”切换自动精简/全部/隐藏。
5. 看完原始轨迹后，打开“配置”，调整两段边界，确认 G1 在前、G2 在后、两段不重叠，然后勾选两个“边界已确认”并保存。

对这批数据，建议值可能大约落在 G1 `1.9–8.3 min`、G2 `13.1–20.0 min`。它们只是峰形建议，不是写死在软件里的 HSC1 常量。

如果更换 LIF 文件、通道或检测器，旧建议会自动变成失效，需要重新分析。

## 4. 完成时间校准

全部边界确认后：

1. 在“前段参考校准”逐段接受可信 anchor。
2. 点击“用已接受参考 anchors 预览重算”，核对内点数和残差。
3. 点击“应用 QC 对齐”。HSC1 应只显示一个 Green 共享轴平移。
4. 进入“无标签后段 delta”，从 24 min 开始估计。如果 2.5 min 内证据不足，可在“配置”中扩大取证范围后重算；不要因为证据不足就直接假定为 0。
5. 预览合理后，点击“确认并冻结无标签 delta”。

## 5. 标注、UMAP 和导出

1. 冻结后进入“事件标注 / QC 巡检”。HSC1 的后段 QC 为 disabled，因此这里应只有细胞候选。
2. 如果 G1 和 G2 同时指向同一个 MS event，必须人工选择 LSK 或 Lin−，不能同时接受。
3. 在 Track 和 UMAP 中互相点击，检查两个窗口是否定位到同一个 event，接受/撤销状态是否同步。
4. 点击“导出 Cell/QC 主 CSV”。

主 CSV 为后续 cell 标注保留精简字段；前段 anchor、模型 hash、歧义详情和审计历史留在项目 SQLite 中。`Type` 来自你接受的通道科学身份（LSK 或 Lin−），不会从事件坐标 CSV 的 `Type` 列复制。

## 出错时请记录

如果按钮报错，请记录：

- 点击的按钮；
- 完整报错文字或截图；
- 当时是草稿边界还是已确认边界；
- `HSC1\annotation_app\annotations\annotation.sqlite` 是否已经生成。

不要删除失败项目，保留它便于追踪。
